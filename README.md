### constraintBS

Backend-сервис для бронирования гостиничных номеров, построенный на FastAPI и PostgreSQL.

Основная задача проекта — реализовать полноценный backend с разделением ответственности между API, бизнес-логикой и слоем работы с данными.

**Основные возможности:**

- управление отелями и их номерами;
- CRUD-операции для отелей и номеров;
- поиск номеров по городу, количеству гостей, типу, стоимости и удобствам;
- поиск только доступных номеров на заданный период;
- создание и отмена бронирований;
- проверка вместимости номера;
- предотвращение пересечения бронирований одного номера;
- расчёт стоимости проживания на основе количества ночей;
- валидация входных данных через Pydantic;
- асинхронная работа с PostgreSQL через SQLAlchemy;
- управление схемой базы данных с помощью Alembic.

**Архитектура:**

Проект построен в стиле Modular Monolith с разделением ответственности:

`Router → Service → Repository → PostgreSQL`

- **Router** — HTTP API и обработка входных параметров;
- **Service** — бизнес-логика и правила приложения;
- **Repository** — запросы к базе данных;
- **SQLAlchemy** — ORM и асинхронная работа с PostgreSQL;
- **Alembic** — миграции базы данных.

В дальнейшем архитектура проекта предусматривает интеграцию LLM для преобразования пользовательских запросов на естественном языке в формализованные ограничения поиска и бронирования.
